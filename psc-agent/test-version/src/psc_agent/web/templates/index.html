How accurate is the extraction?

The model reads each paper (without seeing the workbooks) and its answer is compared, value by value, with what a person entered by hand. Pick a run to see its accuracy, or pick a second run to compare two (two models, or with and without the supporting information). The fairest single number is Match, of those in the PDF text: some hand-entered values (recipes, suppliers) are only in the supporting information, which a PDF-only run cannot find.

Run an evaluation

Extracts the chosen papers (only papers that have hand-entered workbooks) and scores the result against them. The finished papers appear above as soon as each one is done. It costs model calls: roughly 4 per paper, about $0.1 to $0.8 per paper depending on the model. Supporting information in original paper/SI/ is read too.

The model re-reads the paper without seeing the recorded values. Code then compares cell by cell and every quote is checked against its page.

2 · Supporting information (SI)

Recipes, suppliers and extra tables are often only in the SI. It is settled before the paper is read, so the extraction reads the paper and its SI together, once. The first check reads the paper's text with rules and costs nothing; press "Read the paper for its SI (model)" to let a model read it instead (under a cent with Haiku), which also pulls out the SI address when the paper prints one.

3 · Extract

A Big model maps the devices first. The extract model fills the sheets, and a small model decides accept / verify_more / revise per row.

Output: one .xlsx per device in the Raw Data layout, plus review.csv. Check every verify_more row before moving the files into Raw Data.

Download CSV Download Markdown

The goal of the research is to find insights from the extracted papers (which class of substance changes the device results, how and through which channel), not to tune a PCE or a retention value. Each column is rated by how much that analysis needs it, so the dataset can be cut down to what matters.

  • core: the analysis reads it: what was changed, what happened, through which mechanism.
  • context: needed to compare fairly (control, perovskite composition, measurement condition).
  • provenance: identifiers and source traces; kept for joins and audit, not analysed.
  • drop: redundant, constant, empty or a raw leftover: a candidate to remove.
