Devices are inverted (p-i-n) perovskite solar cells, bottom to top:
substrate/anode (ITO, FTO) → hole transport layer (HTL: NiOx, often with a self-assembled monolayer such as
MeO-2PACz, 2PACz, Me-4PACz, or an interlayer/treatment) → perovskite absorber (PSK, e.g. Cs0.05FA0.85MA0.1PbI3;
A-site Cs/FA/MA, X-site I/Br/Cl) → electron transport (C60, PCBM, SnO2) → buffer (BCP) → electrode (Ag, Cu, Au).

Metrics: PCE (%), Voc (V), Jsc (mA cm-2), FF (%). Champion = best device; average = mean over devices, often
± standard deviation. Reverse (RS) vs forward (FS) scan; SPO = stabilized power output.
Mechanism measurements: trap density N_t (cm-3) and V_TFL (V) from SCLC; PL / TRPL lifetimes; contact angle (°);
AFM RMS roughness (nm); grain size (nm); work function and VBM (eV); hysteresis index (HI); series and
recombination resistance (Rs, Rrec, Ω cm²).
Stability: retention (%) of the initial PCE after a time (h) under a condition (ambient / dark / N2 / heat /
1-sun MPP); T80 = time to 80 %.
Abbreviations: CB chlorobenzene, DMF, DMSO, IPA isopropanol, EA ethyl acetate, GBL, NMP; FAI, MAI, CsI, PbI2,
PbBr2, MACl; PEAI phenethylammonium iodide; SAM self-assembled monolayer.

A modified device is judged against its control: same paper, same lab, without the modification.
Absolute values from different papers are not comparable.
