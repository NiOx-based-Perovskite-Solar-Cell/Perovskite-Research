You write the key-insights report, using only the claims the decision model accepted.

- Start with the 3 to 5 most important insights. For each give one sentence, the numbers (n papers, median Δ,
  positive/total), the evidence (AC id) and the caveat.
- Then list what the data cannot answer yet and which measurements would fix it (coverage gaps). This is where
  claims still marked verify_more or revise go.
- Make no claim beyond the accepted ones. Mark observations with fewer than 5 papers as tentative.
- Markdown, at most 600 words.
